# CSE5324-HW1-Movie-Kiosk
Guided software engineering tools practice

Movie Kiosk application is meant for movie theater needs in regards to the buying and assignment of movie theater ticket and seats. The kiosk is meant to be a quick stop for movie theater customers. The application is intended to be simple and efficient. 

Use case for buying a movie ticket:

- Primary Actor: Customer
- Precondition: Customer has selected a movie showtime and movie theather seat.
- Main Steps:
    1. Movie Kiosk System provides pay now button for customer
    2. Customer selects buy ticket button
    3. Movie Kiosk System asks for customer input to pay for ticket
    4. Customer fills in data to pay for ticket and selects submit
    5. Movie Kiosk System provides customer with copy of receipt and ticket for movie
- Postcondition: Movie kiosk provides bought ticket to customer
